# Preferências de edição

Escolhas já confirmadas no chat. Valem para todos os vídeos até ela pedir
outra coisa. Atualize este arquivo (e faça commit) sempre que uma preferência mudar.

## Corte (Video Use)

- Cortar sempre: silêncios, hesitações ("ahn", "hã", "é…") e repetições/retomadas,
  mantendo a última tomada. Não precisa pedir confirmação antes de cortar.
- Pausa máxima mantida: 0,35 s (padrão do `auto_cut.py`).
